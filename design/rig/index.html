Editing

Change Pip in Blender

Blender is free. Every pose and move you see here is in one file you can open and adjust by eye.

  1. Install Blender 5.2 LTS from blender.org (free, Mac or Windows).
  2. Open design/rig/blender/pip.blend from the Parlance repo. Press 1 on the number pad (or View › Viewpoint › Front) to see Pip from the front.
  3. Click Pip's bones, switch to Pose Mode, and open the Dope Sheet's Action Editor. Each mood is an action there: pick one, scrub the timeline, and rotate a bone with R to change a pose. Keys go in with I.
  4. Which eyes, beak or wings show is a set of small show_… bones: scale 1 shows a drawing, 0 hides it.
  5. Save, then export with design/rig/blender/build/export.py (Blender's Scripting tab › Open › Run Script), or ask Claude to re-export Pip. The player picks up the new pip.gltf.json.

What changed

  • Pip is traced from your model sheet, so at rest the rig matches the concept line for line.
  • The rig is a Blender file with real bones. Wings bend through bone chains instead of swinging as stiff pieces.
  • The sad and surprised beaks are redrawn: a closed beak with a soft downturned line, and a small round opening.
  • Moods blend into each other. Moves like hop and nod layer on top of whatever mood Pip is in.
