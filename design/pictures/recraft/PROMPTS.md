# Recraft prompts

Generated by `node design/pictures/recraft/prompts.js`. Each prompt is under 950 bytes and stands alone.

## How to use these

1. Pick Recraft's vector illustration style and the newest vector model. If Recraft lets you set colors, enter the Selva palette below.
2. Lena and Jonas are done and set the look. In Recraft, save the two of them as a custom style (or use them as style references), so the other 16 come out in the same hand. Make four versions of each, keep the best, and ask for changes until you like it.
3. Generate the rest of the cast. Use the same canvas shape for all of them (tall, 1:2 or the closest), so one crop works for every face.
4. Generate the 27 scenes in the widest shape Recraft offers (2:1 or 16:9). The app crops it to 320 by 140, so keep nothing important in the top or bottom tenth.
5. Export every file as SVG, not PNG. Name the cast files like lena.svg and the scenes like de-s1.svg.
6. Upload the SVGs to design/pictures/recraft/incoming/ in the GitHub repo (Add file, then Upload files, on the branch ccr-b60380d9-e408p9), or attach them to the chat, and tell me. Send them in batches if you like: the six German characters, then a few scenes, and so on.

## Colors

Outline `#0B2A1E`, Red `#E5483A`, Orange `#FF8A1F`, Yellow `#FFC93C`, Green `#3DAA5C`, Teal `#1FA3A0`, Blue `#2F7BE0`, Sky `#9ED3F2`, Purple `#8B5CC6`, Pink `#F27BA4`, Brown `#9A6234`, Tan `#E6A957`, Cream `#FFF1D6`

## If it goes wrong

- **A background appears.** Add: isolated on a plain transparent background, no ground, no shadow.
- **The outline is thin or uneven.** Add: extra thick, even outline, the same weight on every shape.
- **The proportions look off.** Add: the same stylized proportions as the first character: big head, about one quarter of the body height, relaxed arms, simple hands.
- **The head faces straight on or the wrong way.** Add: head turned three quarters to the viewer's left, like the reference, body facing the viewer.
- **The character is cropped.** Add: the whole body is visible from the top of the head to the soles of the shoes.
- **A scene has people or writing in it.** Add: no people, no signs with writing, no letters, no numbers.
- **The colors are muted or gradient.** Add: flat solid fills, bright saturated colors, no gradients.
